Struktura CRM

Локальная CRM для бизнеса по демонтажу и отделочным работам.

Основные задачи

Поиск потенциальных заказчиков.
Импорт контактов из CSV.
Учёт клиентов, заявок и объектов.
Учёт поступлений, расходов и прибыли.
Подготовка интеграций с Telegram, веб-источниками и Avito.

Технологии

Electron
JavaScript
SQLite

Версия
